# Workstation notes

Assumed daily driver: Dell Pro Max 18 Plus class laptop.

- Keep heavy intermediates on a fast local disk; do not commit them.
- Set `CPOMP_THREADS` in `.env` to a number that leaves the machine interactive.
- Prefer streaming / subset analyses before full WGS or WSI.
- GPU work waits until Year 3 unless a small sklearn/PyTorch CPU prototype is the point.

Recovery is part of the curriculum, not an afterthought: four hours only compounds if sleep and HRV stay usable.

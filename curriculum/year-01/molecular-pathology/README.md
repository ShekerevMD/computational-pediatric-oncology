# Year 1 molecular pathology notes

For each major pediatric entity, keep a one-pager:

- Developmental context
- Defining histology (in words)
- Recurrent drivers / fusions / CN / methylation class
- Standard assays and what they cannot see
- Prognostic vs theranostic distinction
- Adult contrast

Start: neuroblastoma, B-ALL, medulloblastoma, Wilms tumor.
